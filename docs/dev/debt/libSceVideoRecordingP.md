- [sceVideoRecordingGetStatus, sceVideoRecordingOpen, sceVideoRecordingStart, sceVideoRecordingStop, sceVideoRecordingClose](../../../core/libs/prx/libSceVideoRecordingP/Export.cpp) (libSceVideoRecording) - the signatures, the 16-byte `{Size, RingSec, Format}` parameter, the `None = 0`, `Running = 1`, `Paused = 2` statuses, the `Mp4AvcAac = 0` and `WebmVp9Opus = 1` containers, the 1023-byte path limit and the 3600-second ring limit are from the PS5 GDK bindings in [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/main/src/SharpProspero/Interop/Video/VideoRecording.cs), whose declarations match the ones here one for one; that the console library behaves as that wrapper describes is not read from the console's binary, and the PS4 `libSceVideoRecording` in [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/master/include/orbis/VideoRecording.h) declares the same names without types. The recorder is a session state machine here: a session opens paused, runs, pauses and closes, and `sceVideoRecordingGetStatus` reports which state it is in, where those exports used to throw. Nothing is encoded, no file is written and the caller's heap is not used, so a title that reaches the lifecycle runs without producing video and `sceVideoRecordingClose` drops the session on both values of its argument. A parameter `Size` above 16 is accepted so that a newer structure still opens, and a heap the console would have rejected is not checked, because the size it wants comes from `sceVideoRecordingQueryMemSize`, which stays unimplemented: that binding asks it for the bytes it needs for the settings in the parameter, so its answer is parameter-dependent and the 4096-byte maximum the same file documents is not it. The return values are 0 and the console's codes for a bad path, container, ring length or heap are not measured. No title in this tree is known to call this library, so the effect of this on a title is unverified
- [sceVideoRecordingQueryParam](../../../core/libs/prx/libSceVideoRecordingP/Export.cpp) (libSceVideoRecording) is the call that binding makes before opening, to fill the parameter with the service's own defaults; it is added as a throwing stub by [#6293](https://github.com/boykopovar/AnyPS5/pull/6293), so a title that fills its parameter that way still stops there
